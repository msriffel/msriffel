## 👨‍💻 Sobre mim

Olá! Sou **Matias Samuel Riffel**, estudante de Engenharia de Computação e desenvolvedor Full Stack.

Minha trajetória une desenvolvimento de software e experiência em operações logísticas. Gosto de transformar problemas do dia a dia em soluções tecnológicas que automatizam processos, integram sistemas e facilitam a tomada de decisões.

Tenho experiência com desenvolvimento web e mobile, integração de sistemas e projetos que envolvem dados e algoritmos.

## 🚀 Projetos em destaque

### 🚛 Integração EDI — Automação de processos logísticos

**Projeto profissional | Sistema em produção**

Desenvolvimento de uma solução para automatizar o processamento de arquivos EDI, incluindo leitura de informações e geração de arquivos de resposta para integração entre sistemas.

O projeto aplica desenvolvimento de software a uma necessidade operacional real, reduzindo a dependência de procedimentos manuais.

`Integração de sistemas` `EDI` `Automação` `Logística`

*Projeto de uso empresarial — repositório privado.*

---

### 🗺️ TCC Routing — Roteirização para veículos de grande porte

**Projeto acadêmico | Em desenvolvimento**

Projeto de Engenharia de Computação voltado à modelagem de rotas que consideram características físicas dos veículos, como altura, largura, comprimento e peso.

A proposta utiliza dados do OpenStreetMap e algoritmos de grafos para apoiar a escolha de trajetos, identificar restrições conhecidas e sinalizar incertezas nas informações disponíveis.

**Tecnologias e conceitos:**

`Python` `OpenStreetMap` `Overpass API` `Grafos` `Dijkstra` `A*`

*Projeto de conclusão de curso — repositório privado.*
